## 🔨 Recent Work

### [DataForge ML](https://github.com/rohitbagal1819/DataForge-ML)

* AI/ML-powered dataset quality and preprocessing platform that turns messy CSV/Excel files into clean, ML-ready data
* Detects missing values, duplicates, outliers and inconsistencies, gives a 0–100 data quality score, and visualizes before/after results
* Cleaning pipeline with IsolationForest and IQR capping, plus StandardScaler/OneHotEncoder preprocessing and optional Random Forest evaluation
* React (Vite), Node/Express, FastAPI, Pandas, Scikit-learn
* 🔗 [Repo](https://github.com/rohitbagal1819/DataForge-ML) · 🌐 [Live Demo](https://data-forge-ml.vercel.app)

### [PermitFlow MCP Server](https://github.com/rohitbagal1819/PermitFlow-MCP)

* MCP server acting as an AI co-pilot for construction permitting, built around the startup PermitFlow
* 7 tools (GO / NO-GO readiness audit, fee & SLA estimation, contractor verification, AHJ response letter generation), 5 live resources and 4 reusable prompts
* BM25 RAG over municipal building codes with ~94.9% token reduction versus dumping raw documents
* Works with Claude Desktop and Cursor
* Python 3.11+, MCP, uv
* 🔗 [Repo](https://github.com/rohitbagal1819/PermitFlow-MCP) · ▶️ [Demo Video](https://drive.google.com/file/d/1Q7kjDj28XWBAHAi5OtZCaVF3Ypx0wF-U/view?usp=sharing)

### [Blogger Multi-Agent](https://github.com/rohitbagal1819/Blogger_Multi_Agent)

* Autonomous multi-agent AI system powered by LangGraph & Google Gemini
* 4 specialized agents (Orchestrator, Researcher, Writer, Reviewer) coordinated through a cyclical state machine to plan, research, write and review content
* Python, LangGraph, Google Gemini
* 🔗 [Repo](https://github.com/rohitbagal1819/Blogger_Multi_Agent)

### [BlogWriter MCP](https://github.com/rohitbagal1819/BlogWriter-MCP)

* Blogger Publishing Assistant: a FastMCP server that connects Claude to the official Google Blogger API, so a post goes from idea to live without copy-pasting into the Blogger editor
* Exactly 3 MCP primitives: the `publish_blog_post` tool (title, content, labels, optional draft), the `blogger://posts/recent` resource (matches tone and avoids repeat topics) and the `create_blog_post` prompt (structured writing template)
* Converts Markdown to HTML, uses Google OAuth 2.0 for sign-in, and works with Claude Desktop
* Includes a `test_server.py` that checks the 1 tool / 1 resource / 1 prompt structure
* Python, FastMCP, Google Blogger API v3, OAuth 2.0
* 🔗 [Repo](https://github.com/rohitbagal1819/BlogWriter-MCP)
