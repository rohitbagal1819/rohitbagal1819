## 🚀 Featured Projects

### 📊 [DataForge ML](https://github.com/rohitbagal1819/DataForge-ML)
> **Transform messy datasets into clean, ML-ready data.**

An AI/ML-powered dataset quality and preprocessing platform. Upload CSV/Excel files, detect missing values, duplicates, outliers and inconsistencies, visualize data quality, auto-preprocess the data and download the cleaned output.

- 🧮 Data quality scoring (0–100) with IQR outlier detection & IsolationForest
- 🧹 Automated cleaning pipeline + ML preprocessing (StandardScaler, OneHotEncoder, ColumnTransformer)
- 📈 Before/after visualizations and optional model evaluation (Random Forest)
- 🏗️ 3-tier architecture: **React (Vite) → Node/Express → Python FastAPI**

**Tech:** `React` `Vite` `Node.js` `Express` `FastAPI` `Pandas` `Scikit-learn` `Matplotlib`

[![Repo](https://img.shields.io/badge/📂_Repository-DataForge--ML-181717?style=for-the-badge&logo=github)](https://github.com/rohitbagal1819/DataForge-ML)

### 🏗️ [PermitFlow MCP Server](https://github.com/rohitbagal1819/PermitFlow-MCP)
> **Autonomous Portfolio Permitting Intelligence & Pre-Construction Engine**

An MCP server that works as an AI co-pilot for construction permitting (built around the startup PermitFlow). Works with Claude Desktop and Cursor.

- 🔧 **7 tools** – readiness audit (GO / NO-GO), fee & SLA estimation, contractor verification, AHJ response letter generation and more
- 📡 **5 live resources** and **4 reusable prompts**
- 🔍 BM25 RAG over municipal building codes – **~94.9% token reduction** vs. raw document dumping
- ✅ 100% test pass rate across tools, resources, prompts

**Tech:** `Python 3.11+` `MCP` `uv` `BM25 RAG`

[![Repo](https://img.shields.io/badge/📂_Repository-PermitFlow--MCP-181717?style=for-the-badge&logo=github)](https://github.com/rohitbagal1819/PermitFlow-MCP)
